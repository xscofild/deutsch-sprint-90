# Deutsch Klar — немецкий для жизни в Германии

Одно мобильное приложение для уверенного A2 и подготовки к платному курсу B1 до 31 декабря 2026 года.

## Что работает
- 496 двуязычных слов и фраз, собранных из двух собственных проектов + отдельная прикладная лексика
- три направления: Alltag (быт), Fahrschule (вождение), Arbeit & IT (работа, QA, собеседования)
- ежедневная сессия: **максимум 12 новых** + слова к повторению
- интервалы SRS после успешных ответов: **1 → 3 → 7 → 14 → 30 дней**
- запоминание без самoобмана: сначала вспомни перевод, затем открой и оцени ответ
- 26 грамматических тем A1–B1: объяснение, формула, примеры и упражнения
- 14 разговорных наборов: немецкие фразы с русским переводом и озвучиванием
- мини-тесты на базе 60 вопросов, учёт ошибок и статистика
- светлая и тёмная темы, адаптация под iPhone
- экспорт/импорт прогресса в JSON

## Установка
Репозиторий уже использует GitHub Pages; открой его опубликованный адрес в Safari.
**На iPhone:** Safari → Поделиться → На экран «Домой».

Если GitHub Pages не включены: Settings → Pages → Deploy from a branch → main → /(root) → Save.

Для локального запуска:
```bash
python3 -m http.server 8000
```
Открывай `http://localhost:8000`, не `file://`, чтобы работал `fetch()`.

## Структура
- `index.html` — компактная оболочка
- `styles.css` — дизайн, iPhone и тёмная тема
- `app.js` — интерфейс, обучение, тесты, SRS и статистика
- `data/core.json` — объединённый словарь с RU-переводом, примерами и формами глаголов
- `data/essentials.json` — вождение, работа, IT
- `data/grammar-core.json` — 26 уроков грамматики
- `data/speaking.json` — разговорные ситуации
- `data/tests.json` — тестовые задания
- `data/vocabulary.json` — исходные 90 карточек для миграции старого прогресса

## Ограничения
- **496 карточек — не весь словарный минимум A1–B1.** Это первая отобранная рабочая база. Остальное нужно добрать и проверить до учебного курса. Не переноси автоматически 1000+ слов без перевода.
- Не все унаследованные словарные записи имеют русский перевод примера — такие переводы не выдуманы.
- Озвучивание через браузерное `speechSynthesis` (качество голоса зависит от iPhone/браузера). Автоматической оценки произношения нет.
- Прогресс хранится **только в localStorage данного браузера**; нет входа и синхронизации между устройствами. Сохраняй JSON-бэкап.
- При первом запуске пытается перенести часть прогресса из старых проектов, если Safari на том же домене его сохранил.
- План рассчитан на закрепление A2 и базовую готовность к B1; приложение не заменяет разговорную практику с преподавателем.

## Происхождение
Собраны и нормализованы данные из двух проектов `-DEUTSCH-90` и `deutsch-sprint-90`. Старые исходники не удалять до проверки резервных копий, а GitHub Pages переключать только после успешного тестирования.
